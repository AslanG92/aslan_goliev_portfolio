# Interactive Neumorphic Portfolio Dashboard

An engineering-focused, hyper-polished interactive portfolio built with **React 19** and **Vite**. This dashboard showcases a seamless integration of rigorous logic (Applied Mathematics background), complex state management, and high-fidelity spatial design (3D Blender asset mapping).

The interface completely re-imagines custom desktop layout mechanics with an accessibility-compliant **Neumorphic (Soft Design) UI**, featuring dynamic dark/light theme persistence and an engineered modular navigation sidebar.

---

## Core Architectural Highlights

- **State-Driven Dynamic Theme Engine:** System-aware theme initializing (`prefers-color-scheme`) combined with instantaneous layout context updates using custom HTML5 data-attributes (`data-theme`).
- **Neumorphic Tactility Mechanics:** UI components utilize precise custom CSS shadow-casting matrix boundaries to handle fluid active states (`inset` depths) upon user interaction.
- **Production-Ready Mobile & Web Showcases:** Features interactive case studies ranging from custom cross-platform Mobile Mesh Messengers (**React Native / Expo**) to hyper-optimized Web Commerce Engines (**Next.js / Turbopack**).
- **Figma-to-Code Blueprint Engineering:** Specialized layouts structurally translated from strict Figma canvas design schemas utilizing highly organized **SASS/SCSS and BEM specifications**.
- **3D Spatial Asset Integration:** Smooth rendering loops using hardware-accelerated video containers mapping internal **Blender 3D workflows** and physics animations directly into the core DOM flow.

---

## Engineered Tech Stack

- **Core Logic & Compilation:** React 19 (Hooks, Concurrent Architecture), Vite Bundler, Vanilla JavaScript ES6+, TypeScript.
- **Layout Engineering & Optimization:** Modern Native CSS Nesting, SASS/SCSS, BEM Architecture, Bootstrap Icons Core.
- **Creative Hardware Pipeline:** Blender 3D (Spatial modeling, timeline mechanics, custom texturing).

## Local Development & Deployment Matrix

```bash
cd AslanG92.github.io

# Install production and development dependencies

npm run build
```
